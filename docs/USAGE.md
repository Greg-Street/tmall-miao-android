# 淘宝活动助手 · 0.2.9

通过已授权的 Shizuku 在手机上处理淘宝活动中的浏览、搜索和应用访问任务。Android 11 及以上，仅 ARM64；需要 Shizuku v13 或以上。无需开启无障碍，日常使用不需要电脑。

## 安装和启动

1. 停止旧任务，覆盖安装 `TaobaoActivityAssistant-Android-0.2.9-arm64.apk`。包名、签名及已保存的设置保持一致。
2. 按 [Shizuku 官方指南](https://shizuku.rikka.app/zh-hans/guide/setup/) 通过手机无线调试配对、启动 Shizuku。
3. 回到助手，点击「授权 Shizuku / 重新连接」，允许授权和显示悬浮窗。
4. 淘宝登录后保持竖屏、解锁，点击「开始执行」。运行中可通过悬浮窗暂停、继续或停止。

手机重启后需要重新启动 Shizuku。若仍有旧版无障碍开关，请关闭它。Shizuku 断线时暂停并保留悬浮窗；主动撤销授权可能导致管理器强停助手。

## 设置与行为

- 默认上限 80 次、允许跨应用访问；无时长访问任务停留 2 秒，明确浏览任务按要求加 1 秒。时间可自行修改，升级保留已保存的值。
- 仅执行「做任务赚能量」任务列表；先执行当前画面中靠上的任务，当前无待执行项时先向上复查，再向下查找。列表耗尽后结束本轮，停留在任务列表。已移除足迹、大牌抵扣、首页搜索和首页浏览等补充任务的识别与执行；进入主列表所需的「去赚能量」入口定位保留。
- 首次自动进入活动仍可直接打开固定淘金币频道。普通淘宝内浏览、搜索及闪购完成后，按返回键逐层回到原任务列表，已经回到列表时直接复用；只在实际访问外部应用后使用直达返回。暂停继续和普通任务异常恢复沿用该区别。
- 搜索使用 80 个不同的中文商品词，开始一轮时随机排序，本轮内不重复，例：台灯、保温杯、机械键盘、收纳盒、双肩包。通过应用内置的临时输入服务提交中文和搜索动作，不改动剪贴板；确认商品列表后才开始浏览。
- 每项任务点击前保留 250～600 毫秒停顿，触点在按钮中央范围内变化。浏览的每轮滑动及识别间隔至少 1.5 秒，包含手势和识别耗时；本身已超过该时间时不再追加等待。手势时长 300～550 毫秒，保留内容区上下滑及左右短滑，避开边缘、顶部导航和底部购买栏。实际间隔还受系统执行和 OCR 耗时影响。
- 任务列表仍以最大宽度 1080 识别，浏览画面改为 720，减少识别像素；截图直接解码为可编辑位图，去掉解码后的一次整图复制。明确浏览时长仍按任务要求加用户补时，超过 1 秒的单次识别间隔会补时，不把长时间静止全部算作有效浏览。可见倒计时持续不结束且达到 90 秒时记异常并有限恢复，不记为已执行。
- 「搜一機 / 搜一机 / 搜一擅你……」等指定错字统一为「搜一搜你……」，使用相同任务标识；其他文字和需要人工处理的规则保留。
- 点淘（含点海、点陶、点掏等 OCR 错字）及百度任务跳过；仅有「直播」二字不会跳过。交易、订阅、邀请、安装、答题和明确互动任务仍由本人处理。
- 闲鱼、支付宝等应用访问完成后，直接唤起淘金币频道，外部应用保留在后台，不等待双击返回退出。只为离开已确认的外部访问页面而导航，不点击其退出或确认按钮。
- 不比较前后奖励或进度。操作完成后定位下一项；「已执行」「领取点击」只是操作次数，不表示完成或到账。
- 识别和返回失败先有限重试。普通任务意外退到淘宝首页时使用可见入口恢复，入口缺失则暂停，不改用直达或反复下拉。遇到安全验证、登录、授权或支付时保留悬浮窗，处理后点击继续。图片拖放验证使用「所有图片 / 指定区域 / 反馈码 / 拖放」等多项文字线索识别；只暂停，不自动解答或提交。
- 日志在页面底部显示，开始新一轮时重置；没有导出或磁盘历史，应用进程结束后不保留记录。

图标为生成的卡通金币角色，资源说明见 [ICON.md](ICON.md)。

## 权限与数据

截图仅在内存离线识别，不保存、不上传。本助手无联网和存储权限，不注册无障碍服务。Shizuku 执行截图、前台识别、点击、滑动、返回、输入及打开淘宝；普通悬浮窗需要单独授权。

中文输入期间，Shizuku 临时启用并选择本应用的「淘宝活动助手·临时中文输入」，提交后恢复原键盘；原先未启用的临时服务会重新禁用。该服务仅向淘宝的非密码文字框提交本轮商品词，不读取键入内容或剪贴板。暂停、停止及服务清理也会尝试恢复键盘。若系统强杀、Shizuku 断线或系统拒绝恢复，请在系统输入法选择器切回常用键盘后继续；未完成此机型的输入切换实测。

Android 13 及以上使用系统 `cmd input`，Android 11～12 使用系统 `input`，不反射隐藏输入接口。每个操作检查前台应用和当前执行令牌，命令有输出、超时、取消限制。暂停后不会开始下一步，但系统已经开始的一次短手势可能先完成。

系统命令仍使用直线轨迹，没有模拟压力、设备指纹或验证码通过。随机节奏不能保证规避平台风控、账号限制或奖励取消。平台会综合判断异常行为，参见 [淘金币通用规范](https://terms.alicdn.com/legal-agreement/terms/common_product_agreement/20240903195440263/20240903195440263.html)。本轮未进行手机实测。

## 构建

JDK 17、Android SDK 35、Build Tools 35.0.0：

```powershell
.\gradlew.bat --no-daemon --console plain testDebugUnitTest assembleDebug lintDebug
```

APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。本次改动见 [CHANGELOG.md](CHANGELOG.md)，测试及未实测范围见 [VALIDATION.md](VALIDATION.md)。来源和第三方许可见 [ATTRIBUTION.md](../ATTRIBUTION.md)。
