# 0.2.9

修复搜索任务 OCR 错字，并减少连续执行的识别与滑动负载。

- 在任务标题分类前，将「搜一機 / 搜一机 / 搜一擅你……」统一为「搜一搜你……」。搜索类型和任务标识同时纠正，不再因这些标题错字跳过，或把同一任务当成多个任务重复执行。不全局替换「機」等汉字，人工操作与跳过规则保留。
- 浏览每轮开始时间至少间隔 1500 毫秒，手势、截图和 OCR 耗时计入间隔；一轮已较慢时不再额外等待。5 秒 / 15 秒及用户补时不额外加长，OCR 过慢和可见倒计时补时沿用原规则。
- 浏览 OCR 最大宽度从 900 降为 720，同长宽比输入的像素数约减少 36%；任务列表维持 1080。此比例仅指图像像素数，不是实测功耗或温度下降比例。
- 截图直接解码为可修改的 ARGB 位图，去掉解码后的一次原尺寸复制。继续保留截图释放、超时 OCR 图像所有权和离线处理。
- 没有加入系统温控自动暂停。验证、登录、授权等原有暂停行为保留；0.2.8 移除的首页补充任务保持移除。
- 版本 0.2.9 / versionCode 24，Shizuku 协议仍为 5，包名、签名、图标及默认设置保持不变。

## 验证

新增 4 项检查，变更前 3 项失败，分别复现错字分类、无时长时跳过，以及快速设备过密滑动 / 识别。修复后完整 198 项通过，包括标题归一化、键标识一致、人工操作限制、低延迟时请求次数与间隔、5 秒 / 15 秒时长、慢 OCR 补时、验证出现后停止手势和普通 / 跨应用返回。

未在目标手机测量温度、功耗或 OCR 效果，不能保证发热完全消失。验证范围见 [VALIDATION.md](VALIDATION.md)。
